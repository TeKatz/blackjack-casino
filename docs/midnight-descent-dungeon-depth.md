# Dungeon depth polish
Each floor now has 26 nodes: eight three-lane branching columns, entry and boss. Every route crosses 6/7/7 mandatory combat rooms including entry; floor 2 requires one elite and floor 3 two. Boss availability is enforced in the model as well as the UI. Service rooms return to the map. Floor 1 pressure-plate spikes, floor 2 persistent slowing spore pools and two-wave elites, floor 3 telegraphed rune lanes and two-wave elites. Distinct root islands, tomb corridors and decorative biome features. All 48 relic IDs, art and persistent profile data remain intact. Reward healing and normal relic chance reduced slightly. Tests verify graph connectivity and combat cuts across 72 seeded floors plus three-floor simulated completion. Balance still needs manual gameplay testing.
