# Phase 4 — Casino Presentation & Polish

Phase 4 moves the game from a functional blackjack table toward a desktop game that feels pleasant to keep open and play for longer sessions.

## First Phase 4 slice

- three live table themes: Classic Green, Midnight Blue and Burgundy;
- lightweight card entrance animations with staggered dealing motion;
- optional Windows sound feedback for chips, cards and hand outcomes;
- F11 fullscreen toggle;
- persistent presentation preferences;
- persistent Solo / Full Table choice, AI seat count and selected bet;
- persistent Stable / Development update channel;
- persistent window size/maximized state;
- updater compatibility checks now use the bundled updater executable's actual product version.

All presentation effects are optional. Disabling sound or card animations does not change game state or shoe behavior.

## Later Phase 4 work

The same presentation layer can now grow into richer card/chip assets, dedicated casino sound assets, dealer voice lines, table layouts and more advanced animation choreography without changing the blackjack engine.
